# Udemy Clone

A simple **Udemy website clone** built using **HTML and CSS** to practice webpage structure, styling, and layout techniques.

## 📌 About the Project

This project recreates the basic look and layout of an online learning platform inspired by Udemy. It was created as a practice project to improve my understanding of **HTML, CSS, and Flexbox**.

## ✨ Features

* 🏠 Home page with a navigation bar
* 📚 Course categories and course sections
* 🎓 Course cards with images and information
* 🔍 Search bar UI
* 📱 Structured and organized webpage layout
* 📐 Flexbox used for arranging and aligning elements

## 🛠️ Technologies Used

* **HTML5**
* **CSS3**
* **CSS Flexbox**

## 📂 Project Structure

```text
udemy-clone/
│
├── index.html
├── style.css
├── images/
└── README.md
```

## 🎯 What I Learned

Through this project, I practiced:

* Creating webpage structures using HTML
* Styling elements using CSS
* Using **Flexbox** for layouts and alignment
* Creating reusable course card layouts
* Working with images and navigation elements
* Organizing a frontend project

## 🚀 How to Run

1. Clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
